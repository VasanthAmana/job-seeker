# Decision records

A spike or a choice made during a phase is written up here (execution plan
section 2, rule 7), one file per decision, named `slug.md` (for example
`storage-driver.md`, `mcp-clients.md`). Copy [TEMPLATE.md](TEMPLATE.md).

A phase that changes a design decision also updates `docs/design.md` in the
same pull request; the record here explains *why*, the design doc states
*what*.

Remember the repository is public: records carry the reasoning and the
outcome, never personal data, account details or captures.
